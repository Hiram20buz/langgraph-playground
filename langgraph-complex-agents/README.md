# LangGraph Complete Course – Complex AI Agents with Python

This repository contains code, notes, and exercises from the **LangGraph Complete Course** by freeCodeCamp.org. It serves as a practical guide to mastering **LangGraph**, **LangChain**, and building stateful, multi-agent AI systems.

**📺 Watch the Course:** [LangGraph Complete Course for Beginners – Complex AI Agents with Python](https://www.youtube.com/watch?v=jGg_1h0qzaM)  
**👨‍🏫 Instructor:** Vbeca

---

## 🚀 About This Repository

This project is a code-along journey through the fundamentals of graph-based AI agent orchestration. It starts with basic graph theory concepts (Nodes, Edges, State) and progresses to building complex, production-ready agents including RAG systems and Human-in-the-loop workflows.
